# Dependencies for services/inference/local_server.py — the laptop-only
# EigenPlaces service. NOT the Modal image: that one is pinned inline in app.py's
# PIP_PACKAGES (and cross-checked against requirements.txt at deploy time), and
# it carries GeoCLIP / MegaLoc / DINOv2, CUDA-flavoured torch, and FastAPI.
#
# Kept out of services/harvest/requirements.txt on purpose. That file is what a
# harvest run needs — httpx and psycopg — and adding torch to it would make
# `harvest.py run` a 700 MB install for a job that never touches a model.
#
# SIZE, UP FRONT
#   torch 2.13.0 (macOS arm64) is the big one; with torchvision, numpy, sympy,
#   networkx and the rest the resulting venv measures **729 MB on disk**. Budget
#   a few minutes on a normal connection.
#
#   The first server start additionally clones gmberton/EigenPlaces and
#   gmberton/cosplace from GitHub and downloads two checkpoints
#   (ResNet50_512_eigenplaces.pth + the CosPlace ResNet50_512 the backbone is
#   initialised from), ~110 MB, cached under .lantage-models/torch. Later starts
#   need no network.
#
# INSTALL
#   python3 -m venv services/inference/.venv
#   services/inference/.venv/bin/pip install -r services/inference/requirements-local.txt
#
# Verified on Python 3.14.6, macOS arm64, 2026-07-31. No fastapi/uvicorn: the
# server is stdlib ThreadingHTTPServer, which is one fewer thing to install and
# entirely adequate for one operator embedding 1,593 thumbnails.

torch==2.13.0
torchvision==0.28.0
pillow>=10.4,<12
numpy>=1.26,<3
httpx>=0.27,<1
